# 设备职责与部署

本文档描述每台设备在 SmartCore v1 中承担的职责、运行组件和不承担的内容。

## 设备总览

| 设备 | v1 角色 | 是否必须常驻 | 核心职责 |
| --- | --- | --- | --- |
| 公网服务器 | 主控节点 | 是 | 运行应用、数据库、调度器、飞书回调、备份 |
| 手机 | 用户入口 | 否 | 接收飞书提醒，访问内部 Web 面板 |
| 电脑 | 管理与开发终端 | 否 | 维护项目，查看面板，导入课表 |
| 树莓派 | 备份节点 | 建议常驻 | 接收服务器数据库快照 |

## 公网服务器

### 运行组件

服务器上使用 Docker Compose 运行：

- `caddy`
  - 负责 HTTPS 证书。
  - 接收公网流量。
  - 只把 `/feishu/event` 转发给应用。
- `app`
  - Python FastAPI 应用。
  - 提供飞书事件回调。
  - 提供内部 Web 面板。
  - 运行提醒调度器。
  - 管理 SQLite 数据库。
  - 执行备份脚本。

### 保存的数据

服务器是唯一权威数据源，保存：

- 课表。
- 作业和 DDL。
- 生活事项。
- 提醒队列。
- 飞书消息日志。
- 用户偏好配置。

### 服务器上不应该暴露的东西

- SQLite 数据库文件。
- Web 管理面板公网入口。
- 内部 API。
- 备份目录。
- `.env`、`passwd.txt`、SSH key、飞书密钥。

## 手机

### 主要用途

手机是日常使用入口：

- 在飞书里接收晨报、课前提醒、DDL 提醒、明日预告。
- 在飞书里发送简单命令，例如：
  - `今日`
  - `明日`
  - `本周DDL`
  - `添加作业 高数 周五 23:59 交习题3`
  - `添加事项 明天 18:00 取快递`
- 通过 Tailscale 访问内部 Web 面板，进行更复杂的编辑。

### 手机不承担的职责

- 不保存权威数据库。
- 不运行调度器。
- 不负责备份。
- 不要求一直在线。

## 电脑

### 主要用途

电脑是管理和开发终端：

- 编写和维护代码。
- 修改 Docker Compose、Caddy 配置和示例配置。
- 导入或编辑课表 CSV。
- 通过 Tailscale 访问内部 Web 面板。
- 查看服务日志。
- 在必要时执行恢复脚本。

### 可选后续能力

v1 先不让电脑进入核心运行链路。后续可以把电脑作为执行节点：

- 浏览器自动化。
- 学习资料整理。
- 本地文件索引。
- 课程资料摘要。

这些能力需要单独设计执行器协议，避免电脑离线时影响核心提醒。

## 树莓派

### v1 主要用途

树莓派作为备份接收节点：

- 通过 Tailscale 被服务器访问。
- 通过 SSH 接收 `rsync` 同步。
- 保存服务器发来的 SQLite 快照。
- 保留比服务器更长的备份周期。

推荐目录：

```text
/home/pi/smartcore-backups
```

如果树莓派用户名不是 `pi`，部署时用配置文件指定，例如：

```text
PI_USER=your_user
PI_HOST=your-pi-tailnet-name
PI_BACKUP_DIR=/home/your_user/smartcore-backups
```

### 树莓派不承担的职责

- v1 不运行 FastAPI。
- v1 不运行数据库主节点。
- v1 不接管提醒调度。
- v1 不直接对外提供服务。

### 后续扩展方向

树莓派以后可以扩展为：

- 桌面小屏幕，显示今日课表。
- 本地语音播报课前提醒。
- 物理按钮，用于“完成任务”或“稍后提醒”。
- 家庭局域网自动化执行器。
