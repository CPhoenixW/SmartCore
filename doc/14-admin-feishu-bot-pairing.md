# 管理员飞书机器人配对

## 目标与验收

管理员可以在设置页为当前工作账户创建、编辑、启停、删除和测试飞书机器人。凭据只以服务器密文保存，页面和接口都不返回 App Secret、Verification Token 或 Encrypt Key。

每个机器人均可使用同一个回调地址 `/feishu/event`。服务端依据每个启用机器人的签名、加密密钥和验证 Token 匹配回调，随后只使用匹配机器人的凭据回复或转发消息。

管理员选择机器人后发起配对，系统生成十分钟有效的一次性码。用户在该机器人私聊发送 `绑定 <配对码>`，网页显示已认领；管理员确认后才创建设备、关联飞书身份，并把该会话作为机器人的提醒目标。测试按钮只向已绑定会话发送测试消息。

## 数据与迁移

新增 `feishuBot`，保存所属用户、机器人名称、加密凭据、启用状态、默认标记、关联设备、最近测试结果和时间。`devicePair` 增加可空 `botId`，使配对码只能被对应机器人认领。

首次启动会把现有 `FEISHU_*` 环境变量安全导入为 default 用户的“环境默认机器人”，并将既有飞书设备关联到它。环境变量保留为没有数据库机器人时的回退，不会被修改或输出。迁移只增加表和列，不删除用户、设备、身份或消息记录。

## 接口

管理员接口位于 `/api/admin/feishuBots`：列表、创建、更新、删除、启停、测试，以及 `/{botId}/pair/start`。所有接口校验会话中的 actor 必须为管理员，并以当前工作账户作为资源边界。

配对确认继续使用通用 `/api/device/pair/{pairId}/confirm`，并由 `botId` 约束飞书侧认领。机器人回调无管理员会话，只有通过对应凭据验证后才可认领或转发。

## 安全与回滚

加密密钥由现有 `auth_secret()` 派生；数据库泄露不应得到明文飞书密钥。删除机器人会撤销其关联设备令牌并移除身份，且不会修改环境变量。若需回滚代码，现有环境变量回退仍可处理原机器人；数据库新增表可保留，不影响旧代码。

## 测试矩阵

- 管理员创建、读取、修改、启停、删除，普通用户拒绝访问。
- 机器人凭据不出现在 API 响应和日志中。
- 回调只接受匹配机器人的 Token/签名，错误机器人不能认领其他机器人的码。
- 双方确认后，身份、设备和机器人目标会话建立；测试消息使用该会话。
- 旧环境变量机器人自动导入且现有配对数据不丢失。
