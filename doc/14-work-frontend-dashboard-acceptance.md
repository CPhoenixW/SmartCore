# Work 工作台前端重构验收

## 范围

仅修改 `/work` 浏览器端工作台：

- `app/web/work_routes.py`
- `app/web/static/work.css`
- `app/web/static/work.js`

不修改 `/screen` 手机副屏，不改数据库结构，不要求新增后端接口。

## 产品目标

将 `/work` 从调试面板升级为浅色 B 端个人智能秘书控制台。页面应快速回答：

- 今天要做什么。
- 未来 48 小时有什么 DDL。
- 当前设备是 `working`、`away` 还是 `offline`。
- 提醒路由在工位走副屏，离开走飞书。
- 灵感如何沉淀、转事项、转 DDL 或归档。
- API、设备、日志是否正常。

## 必须实现

- 左侧固定导航：总览、添加事件、事项看板、灵感、课程、设备、日志、设置。
- 顶部工具栏：全局搜索框、工作状态 badge、API 在线 badge、最后更新时间、刷新按钮、用户入口。
- 默认入口为 `事项看板`，不是添加事件。
- 事项看板包含四张摘要卡：今日待办、即将截止、灵感 Inbox、设备状态。
- 事项看板包含今日事项紧凑列表、未来 48 小时截止时间线、最近 3 条灵感、提醒路由。
- 添加事件页包含一句话录入、表单分段、创建前预览、常用模板。
- 灵感页是 Inbox 工作流，包含快速记录、open/handled/archived 筛选、转事项、转 DDL、归档操作。
- 设备页包含当前状态卡、状态时间线和状态筛选。
- 日志页包含 notify/msg/act 切换，避免直接堆原始 JSON。
- 所有列表有空状态，写操作有 toast，API 异常不白屏。

## 视觉约束

- 浅色背景 `#F5F7FB`。
- 侧边栏和卡片为白色。
- 主色使用 `#2563EB`。
- 卡片 16px 圆角，低装饰阴影。
- 不使用深色 HUD、霓虹光效、大面积渐变或营销式 hero。
- 表格和列表应紧凑，优先信息效率。
