# 飞书 Markdown、Overview 日期与 DDL 编辑修复

## 目标

在不修改数据库结构和 OpenClaw 回调协议的前提下：

1. `/agent/sendText` 与 `/agent/feedback/send_text` 将最终回复作为飞书 `lark_md` 交互卡片发送，使粗体、列表和段落正常显示。
2. Overview 的事项面板提供上一天、日期选择、今天、下一天四个简洁控件，按所选日期查询事项。
3. Update Event 选择事项时按 ID 读取完整详情；DDL 的计划、提醒和其他字段必须完整进入编辑表单，列表刷新不得用摘要对象覆盖详情。

## 验收标准

- 飞书最终回复中的 `**粗体**` 和 `- 列表` 不再原样显示 Markdown 标记。
- “已收到，正在处理…”仍使用普通文本，不改变现有快速确认流程。
- Overview 可连续切换日期、回到今天，并正确显示所选日期的空状态和事项。
- 点击 DDL 后，标题、描述、状态、优先级、截止时间、硬截止、关联计划、关联提醒均可编辑。
- DDL 表单克隆的数据与 API 原对象隔离，且兼容 Vue 响应式对象。
- Ruff、pytest、Vitest、前端构建和 `/healthz` 均通过。

## 兼容性

- HTTP 请求体和返回结构保持不变；仅飞书侧的消息类型从 `text` 变为 `interactive`。
- 无数据库迁移，无新增运行时依赖。
