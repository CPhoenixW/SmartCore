# 飞书富媒体消息接入

## 验收标准

- 一条富文本消息中的文字与全部图片会作为同一个灵感输入转发给 OpenClaw。
- 单独图片、单独文件，以及富文本中的文件，均会保存在私有附件存储后转发。
- 支持的文件类型仍限制为 PDF、TXT、ZIP，单个附件不超过 20 MB。
- 无法处理的消息不会静默成功：机器人回复支持范围，服务日志仅记录消息 ID、类型和内容字段名，不记录正文或附件内容。
- 所有附件维持用户绑定、私有路径和 Agent scope 的既有鉴权边界。

## 接口与数据

飞书回调和 OpenClaw 事件契约不变。`attachments` 从至多一个附件扩展为零到多个附件；每个附件仍使用既有的临时上传记录和 `/attachments/<private-file>` Agent 路径。

## 风险与回滚

不涉及数据库迁移。回滚到 `a226bc7` 即恢复原先单图/单文件解析。下载、类型和大小校验失败时，事件不转发并向飞书发送明确提示。

## 验证矩阵

- 纯文字转发。
- 单独图片与单独文件。
- 含文字和两张图片的富文本消息。
- 不支持消息类型的显式反馈。
