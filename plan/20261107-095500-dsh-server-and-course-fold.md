# DSH 服务器权限与课程折成计划

## 已确认需求

- 日常事项优先使用 SmartCore 的计划和提醒。
- 已有课程模板折成独立计划，课次、提醒和课程信息保留。
- PWA 助手拥有宿主机的完整读写和命令权限。
- 手机端继续使用左上角菜单；发送栏与按钮同高；静态资源可预缓存。

## 做法

- 启动和课程写入之后，把 `courseEvt` 展开出的计划保留下来，把课程名、教师、地点和周次写入计划描述，再删除课程模板和 `coursePlan` 关联。
- 助手模式增加 `server_list`、`server_read`、`server_write`、`server_exec`。容器以 root 挂载宿主机根目录，并用 `nsenter` 在宿主机命名空间执行命令。
- 后台日报和自动化任务不获得这些服务器工具。
- 不在本次直接部署或改生产库。迁移随下一次应用启动执行。

## 验收

- 折叠后计划还在，课程模板和关联行消失，再次执行不改数据。
- 宿主路径读写在临时目录上可测；命令工具只出现在助手工具列表。
- 相关 Python 测试和 `node --test` 通过。
